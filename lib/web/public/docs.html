API PUBLIK v1

Endpoint untuk pengguna umum — pasang di bot cek-saldo, spreadsheet, n8n/Zapier, atau skrip sendiri. Buat key di panel → Profil → Personal API Key. Batas 60 permintaan/menit per key.

WEBHOOK

Daftarkan URL webhook di panel → Profil → Webhook Event. Setiap request dikirim dengan header X-Manzxy-Signature: sha256=<hmac> — HMAC-SHA256 dari body mentah memakai secret-mu. Contoh verifikasi (Node.js): 
const crypto = require('crypto');
const valid = 'sha256=' + crypto.createHmac('sha256', SECRET).update(rawBody).digest('hex');
if (req.headers['x-manzxy-signature'] !== valid) return res.status(401).end();
EventDikirim saat
topupSaldo masuk (amount, balance, ref)
bot_onlineJadibotmu terhubung
bot_offlineJadibotmu terputus (dengan alasan)
jadibot_createdJadibot baru dibuat
sewa_habisMasa sewa jadibot habis
testTombol "Tes" di panel
