AKUN TERTAUT

🔑 PERSONAL API KEY

Cek saldo & status botmu lewat HTTP sederhana — pasang di bot cek-saldo, spreadsheet, atau skrip sendiri.

belum ada — buat dulu

curl "<panel>/api/v1/me?key=KEYMU"

🔐 PASSKEY

Login pakai fingerprint / FaceID / Windows Hello — tanpa password. Butuh HTTPS atau localhost.

🧩 WIDGET EMBED

Tempel badge saldo/botmu di website, bio link, atau README GitHub.

— buat API key dulu —

Panel kirim POST ke URL-mu saat ada event: saldo masuk, bot online/offline, masa aktif habis. Dokumentasi: /docs

Kirim alert event (saldo masuk, bot online/offline) ke Telegram atau Discord-mu.
