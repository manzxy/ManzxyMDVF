Pertanyaan yang sering muncul

Bagaimana cara bayarnya?

Semua pembayaran lewat QRIS. Setelah kamu scan dan bayar, sistem mengecek status secara berkala dan mengaktifkan layanan otomatis — biasanya dalam hitungan detik sampai satu menit. Tidak perlu konfirmasi manual ke owner.

Apakah bot harus jadi admin grup?

Untuk fitur grup seperti welcome, anti-link, dan moderasi, ya — jadikan bot admin. Fitur dasar tetap jalan tanpa admin, tapi sebagian perintah akan menolak dieksekusi.

Masa aktif habis, apa yang terjadi?

Panel menampilkan peringatan beberapa hari sebelum habis. Kalau tidak diperpanjang, bot berhenti melayani. Kamu bisa perpanjang kapan saja dari panel.

Ada dokumentasi API?

Ada. Endpoint API v1, webhook, dan widget embed dijelaskan di halaman dokumentasi. Status layanan bisa dicek di /health.

Bisa dipakai di HP?

Bisa. Panel ini web app — buka di browser HP dan tambahkan ke Home Screen supaya terasa seperti aplikasi biasa.

Siap punya bot sendiri?

Daftar gratis, bayar hanya saat kamu butuh layanannya.
